title Cadastro de Pessoa Simples - Interação UML baseada no código

actor Usuario
participant Browser
participant AppJS as app.js
participant PessoaJS as Pessoa (Frontend)
participant CadastroPessoaRequest
participant PessoaService
participant PessoaController
participant PessoaRequestMapper
participant CadastrarPessoaCommand
participant CadastrarPessoaUseCase
participant PessoaBackend as Pessoa (Backend)
participant PessoaJdbcRepository
participant PostgreSQL
participant CadastroPessoaResponse

Usuario->Browser: preencher formulário e solicitar cadastro
Browser->AppJS: submit(formPessoaSimples)
activate AppJS

AppJS->PessoaJS: new Pessoa(nome, idade, email, tipoSanguineo)
PessoaJS-->AppJS: pessoa

AppJS->CadastroPessoaRequest: new CadastroPessoaRequest(pessoa)
CadastroPessoaRequest-->AppJS: request

AppJS->PessoaService: cadastrarSimples(request)
activate PessoaService
PessoaService->PessoaController: POST /api/pessoas (JSON)
activate PessoaController

alt [requisição processada sem exceção]
    PessoaController->PessoaRequestMapper: toCommand(request)
    activate PessoaRequestMapper
    PessoaRequestMapper->CadastrarPessoaCommand: CadastrarPessoaCommand(...)
    activate CadastrarPessoaCommand
    CadastrarPessoaCommand->CadastrarPessoaUseCase: executar(this)
    activate CadastrarPessoaUseCase
    CadastrarPessoaUseCase->PessoaBackend: new Pessoa(nomePessoa, emailPessoa)
    PessoaBackend-->CadastrarPessoaUseCase: pessoa com UUID
    CadastrarPessoaUseCase->PessoaJdbcRepository: insert(pessoa)
    activate PessoaJdbcRepository
    PessoaJdbcRepository->PostgreSQL: INSERT pessoa
    PostgreSQL-->PessoaJdbcRepository: sucesso
    deactivate PessoaJdbcRepository
    CadastrarPessoaUseCase-->CadastrarPessoaCommand: pessoa
    deactivate CadastrarPessoaUseCase
    CadastrarPessoaCommand->CadastroPessoaResponse: montar resposta
    CadastroPessoaResponse-->CadastrarPessoaCommand: response
    CadastrarPessoaCommand-->PessoaRequestMapper: response
    deactivate CadastrarPessoaCommand
    PessoaRequestMapper-->PessoaController: response
    deactivate PessoaRequestMapper
    PessoaController-->PessoaService: HTTP 200 + JSON
else [exceção]
    PessoaController-->PessoaService: HTTP 400
end

deactivate PessoaController

alt [HTTP OK]
    PessoaService->CadastroPessoaResponse: new CadastroPessoaResponse(data)
    CadastroPessoaResponse-->PessoaService: response
    PessoaService-->AppJS: response
    deactivate PessoaService
    AppJS->Browser: mostrarResultado(response)
    AppJS->PessoaService: listar()
    note right of AppJS: O frontend atualiza a lista após o cadastro.
else [HTTP não OK]
    PessoaService-->AppJS: Error HTTP status
    deactivate PessoaService
    AppJS->Browser: mostrarErro(erro)
end

deactivate AppJS
